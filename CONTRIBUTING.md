# Contribuire

Grazie per l'interesse a contribuire a questo progetto. Per mantenere il sito coerente e stabile,
segui queste poche regole.

## Prima di iniziare

1. Leggi `README.md` e `CLAUDE.md` per capire struttura e convenzioni del progetto.
2. Apri un issue per discutere modifiche importanti prima di lavorarci.

## Regole di base

- **Modifica solo** `Anna Patanella - Sito.dc.html`: è l'unico file destinato a essere modificato.
- **Non modificare** `support.js` (runtime generato).
- Lo stile è **inline** su ogni elemento: non introdurre classi o fogli di stile esterni.
- Mantieni accessibilità e coerenza: `prefers-reduced-motion`, skip link, `:focus-visible`, attributi `aria-*`.
- Tono dei testi: caldo, sobrio, seconda persona singolare ("tu").

## Flusso di lavoro

1. Crea un branch dal branch principale.
2. Apporta le modifiche.
3. Verifica il risultato a **375px** e **≥960px**.
4. Apri una pull request con una descrizione chiara delle modifiche.

## Commit

Usa messaggi di commit chiari nel formato `<tipo>: <descrizione>` (es. `feat:`, `fix:`, `docs:`).
